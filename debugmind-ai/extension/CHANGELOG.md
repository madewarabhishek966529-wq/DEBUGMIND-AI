# Changelog

All notable changes to the "debugmind-ai" extension will be documented in this file.

## [0.0.1] - Initial Release

- Core **Detect. Explain. Fix. Verify.** developer workflow.
- Pure JavaScript extension architecture for maximum compatibility and lightweight footprint.
- Native VS Code Activity Bar icon and responsive Sidebar Webview UI.
- Local static analyzer combined with Google Gemini AI backend.
- Code Health Score visualization (0–100) with error, warning, and suggestion breakdown.
- In-editor VS Code diagnostics with quick-fix CodeActionProvider (Explain, Fix, Ignore).
- Native diff preview with explicit user Accept / Reject workflow.
- Multi-language test generation for JUnit, Jest, PyTest, Flutter, and PHPUnit.
- Deterministic fix verification engine.
- Terminal & stack trace error analyzer.
- Privacy controls with explicit user consent toggles.
